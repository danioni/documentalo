Este sitio documenta lo que corre detrás de los productos de [Grupo Digitalo](https://grupodigitalo.com), para desarrolladores y para quien quiera entender qué hay detrás: cómo se integra Coordinalo, en qué estado está el estándar propuesto Servicialo y qué es el protocolo de conectores Habilitalo. Lo que es intención se dice como intención, con su estado y su fecha.

## Coordinalo

Coordinalo es el producto SaaS en producción: un sistema para organizaciones que entregan servicios profesionales. Incluye tres productos activables, **Coordinalo** (operación), **Planificalo** (finanzas) y **Relacionalo** (clientes). Una organización nueva nace con Coordinalo activo y los otros dos disponibles; la activación es una transición única y no hay pausa ni downgrade. Ver [Productos y activación](/docs/coordinalo/productos).

Un tercero se integra por dos vías. Las dos viven en `coordinalo.com`; no existe el prefijo `/api/v1/`, y Planificalo y Relacionalo no tienen API pública propia: sus rutas son internas de la app y exigen sesión.

| Vía | Base | Credencial | Doc |
|---|---|---|---|
| REST Servicialo, por organización | `https://coordinalo.com/api/servicialo/{orgSlug}/…` | Descubrimiento (`services`, `availability`, `manifest`): sin credencial si la organización está publicada en Servicialo. Ciclo de vida (`sessions/{sessionId}` y sus transiciones): `X-Org-Api-Key: sk_admin_…` o `Authorization: Bearer sk_admin_…`. | [Servicialo → Implementaciones](/docs/servicialo#implementaciones) |
| MCP (Streamable HTTP) | `https://coordinalo.com/api/mcp` | `X-Org-Api-Key: sk_admin_…`. En esta ruta `Authorization: Bearer` es el JWT de sesión de la app, no la API key. | [Servicialo → Dos servidores MCP](/docs/servicialo#dos-servidores-mcp) |

La API key la emite un owner o admin de la organización y se muestra completa una sola vez. No hay OAuth para el MCP ni webhooks salientes.

## Servicialo

Servicialo es un estándar abierto **propuesto** de interoperabilidad para servicios profesionales, con licencia Apache-2.0. Estado: protocolo 0.10 en borrador, HTTP Profile 1.0.0, proceso de RFC (RFC-001) sin ratificar, RFC-005 en período final de comentarios hasta el 2026-09-13. Una implementación registrada: Coordinalo.

## Habilitalo

Habilitalo es un protocolo abierto de conectores para traer el historial desde otras fuentes: un manifiesto JSON declara la fuente de datos y los tipos de evento, y una función pura convierte los datos crudos en eventos canónicos. Su README declara licencia MIT. La documentación propia en este sitio está pendiente.
